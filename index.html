PATHMIND v4 — Mission Briefing

What is PathMind?

PathMind is a terrain-aware pathfinding arena. Five classic search algorithms — each given the name and personality of a well-known AI model — race to navigate a 2D world full of diverse terrain. After the race, a physical robot drives the winning route, visibly slowing in mud, crawling uphill, and gliding on ice.

⚙ How it really works (honest note): The "AI models" are a fun theme — there are no external API calls and no API keys. Each racer is a different pathfinding algorithm (A*, Dijkstra, Greedy Best-First, RRT) running 100% offline in your browser. The company names just make the algorithm tradeoffs memorable.

Terrain System (8 Types)

WALL

Impassable obstacle. No AI can cross.

UPHILL (3×)

Steep incline. Costs 3× base movement — slows all terrain-aware AIs.

DOWNHILL (0.5×)

Descent advantage. Halves movement cost — fast path if routed correctly.

FOREST (4×)

Dense tree cover. 4× cost — only worth it if all other paths are worse.

MUD (5×)

Swamp terrain. Highest passable cost at 5× — AIs must find alternates.

WATER

Impassable water body. Forces detours like walls but appears different.

SAND (2×)

Desert terrain. Moderate 2× cost — acceptable shortcut in some cases.

ICE (0.8×)

Frozen surface. Slightly faster than normal — useful express lane.

The 5 Racers (Algorithm → Persona)

CLAUDE = Weighted A*

Octile heuristic, terrain-aware — methodical and guaranteed to find the lowest-cost path.

GPT-4o = A* (Euclidean)

1.2× weighted heuristic — fast, slightly overestimates, trades a little optimality for speed.

GEMINI PRO = RRT

Goal-biased Rapidly-exploring Random Tree — random sampling creates creative, unexpected paths.

CHATGPT = Dijkstra

No heuristic — explores in all directions, always optimal but slowest (most nodes expanded).

DEEPSEEK = Greedy Best-First

Ignores terrain cost and charges at the goal — fastest compute, but often a costlier route.

How To Use

1. Select a terrain type from the palette and paint the grid. Or load a preset.

2. Place the Robot and Goal using the tool buttons.

3. Hit Race All AIs — watch 5 algorithms find 5 different paths, then the winning robot auto-drives the route.

4. Hit Drive Winner anytime to replay the physical robot. Watch it climb uphill slowly, sink and crawl through mud, and glide fast on ice — the terrain costs become physical motion.

5. Check the Leaderboard for rankings and read the Race Analysis to understand why each AI chose its route.

Why This Matters

Real-world robotics uses terrain-aware pathfinding in Mars rovers (NASA JPL), warehouse robots (Amazon), and self-driving cars. Different algorithms shine in different environments — A* dominates structured grids, RRT excels in high-dimensional spaces, Dijkstra guarantees optimality. PathMind makes these tradeoffs visible and interactive.
